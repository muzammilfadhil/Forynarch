# Forynarch installation UI

Direction: the owner's supplied nine-step installer reference, adapted to a native
desktop window in Forynarch's existing navy and pale blue palette. This reference
explicitly authorizes the hero, feature rows and progress segments.
Antislop DURING remains the selected mode for this session.

ENERGY 2 / RHYTHM 2 / MOTION 3.

- Navy is the existing OS identity, not a generic technology-site theme. Pale blue
  marks the next action and current choice. Peach is reserved for real limitations.
- Use the installed DejaVu Sans family for legibility and complete English glyphs;
  no extra font download or idle service. Welcome uses the product wordmark as text.
- The nine real stages remain in the navigation rail. Slim progress segments above
  the content show the current stage, never simulated installation progress.
- Welcome uses a bounded shader hero and two illustrated feature rows. Rows share
  a desktop grid above 720 px content width and stack at narrower widths. The Live
  Live installer badge reflects its execution context; there is no invented version, new logo or statistic.
- Form content has a bounded reading width. Labels sit above fields; related fields
  share rows. Storage and connection choices are radio rows with real explanations,
  not marketing cards. Review lists the user's exact choices and actual blockers.
- Hero radius is 18 px, feature and notice rows 12 px, fields 5 px and buttons 6 px.
  Repeated form controls retain their legible structure and 44 px targets.
- The single bounded shader draws analytic blue light folds without texture/blur
  sampling, full-window capture or another service. Its 680 ms arrival settles
  completely. There is no idle frame timer or looping animation.
- Stage changes use a 140 ms fade and an 8 px, 200 ms arrival. Reduce motion removes
  both and immediately settles the shader. Footer controls stay outside scrolling.
- The window identifies itself as the Live installer. Missing resources and
  unsupported layouts have specific errors. Installation requires a verified
  executor and final disk-specific consent.
- Desktop minimum is 880 x 620; test that size and the current 1280 x 800 VM display.
  This native installer has no shipped phone/mobile variant.

Antislop rules are applied to this installer scope. The existing desktop's styling
and the user's Windows-interoperability requirements are not discarded.

Compile the shader on Linux with qt6-shadertools. Only its compiled asset enters
Live media; this installer and compiler are not added to the independent target.
Source previews are distinct from the previous ISO and installed RAM acceptance.
