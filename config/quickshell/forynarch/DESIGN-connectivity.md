# Connectivity settings

The owner wants everyday Wi-Fi and Bluetooth pairing without a terminal or the
advanced connection editor as the first screen. Keep the existing navy/blue OS
identity. Antislop DURING is the selected session mode.

ENERGY 2 / RHYTHM 2 / MOTION 2.

- Begin with the radio switch, current connection and a visible Scan action.
  Show nearby networks/devices as readable rows with one next action.
- Connected/saved items precede new discoveries. Signal and security are words as
  well as icons. Do not expose adapter identifiers as the primary device name.
- Password and pairing prompts stay graphical; never put credentials in process
  arguments, logs, status IPC or temporary files. Advanced remains a secondary link.
- Scans are finite and stop when the page closes. No permanent polling or new
  discovery daemon; reuse NetworkManager, BlueZ and the existing native shell.
- Loading, radio-off, missing adapter, no discoveries and failure each explain
  the actual state. Do not show fabricated nearby devices in normal operation.
- Controls use 44 px targets, visible keyboard focus, readable contrast and the
  existing reduced-motion setting. A remembered connection is not an internet claim.
- Validate missing hardware in the VM and synthetic interactions in isolated QML
  tests. Successful real Wi-Fi authentication and Bluetooth pairing require hardware.
